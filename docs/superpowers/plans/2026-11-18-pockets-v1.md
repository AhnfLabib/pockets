# Pockets v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Chrome extension in which a hand-drawn raccoon crawls over the current page and takes one stale or distracting tab at a time, with a warning card, Keep and Undo.

**Architecture:** A Manifest V3 service worker owns all decisions (which tab, when, closing, the taken list) and drives each visit as a state machine. A content script on every site hosts the "stage" (a canvas plus card inside a shadow root) and can change its own tab's icon and title. Rules and the movement rig are pure modules with injected time and randomness so they are unit-tested without a browser.

**Tech Stack:** TypeScript, esbuild, Vitest, Playwright (bundled Chromium, launched with the unpacked extension), Python 3 with numpy and Pillow for the artwork only.

**Spec:** `docs/superpowers/specs/2026-11-18-pockets-design.md`. Movement reference: `docs/spikes/mock-hand-drawn.html`.

## Global Constraints

- Manifest V3. Permissions exactly: `tabs`, `storage`, `alarms`, `idle`, `sessions`, `scripting`, host `<all_urls>`. No others.
- No network requests of any kind from extension code. No analytics.
- **No tab is ever closed unless the warning card was shown on screen for that visit.**
- One tab per visit. One visit at a time across all windows. Only tabs in the focused window are candidates.
- Defaults: stale time 24 h, gap between stale visits 5 min, at most 4 stale tabs per hour, countdown 5 s, 30 s between distracting takes, taken list keeps 200, Undo notice shows about 5 s.
- Default distracting list: `youtube.com, reddit.com, x.com, twitter.com, instagram.com, facebook.com, tiktok.com, netflix.com`.
- The stage canvas ignores the pointer and never takes keyboard focus. Stage DOM lives in a closed shadow root.
- `prefers-reduced-motion: reduce` means no crawl: card top-left, Pockets drawn still beside it.
- Copy in Pockets' voice: "Mine in 5…", "Pockets took {title}", "Fine. Keep it."
- Generated PNGs are committed. Building the extension must not need Python.
- The mock is reference only. Rebuild its movement as tested modules; do not import from `docs/spikes/`.
- All randomness and time are injected (`rand: () => number`, `now: number`); no `Math.random()` or `Date.now()` inside `src/rules` or `src/stage/rig`.

## Review Focus

1. A tab whose address has no ordinary host (`chrome://`, `file://`, `about:blank`, `data:`) must not crash site matching and must never match the distracting list. It is still a stale candidate. → Task 8.
2. The target tab is closed, navigated or moved by the user mid-visit. The visit must abort and no other tab may be closed. → Task 12.
3. The service worker is killed mid-visit (MV3 does this). On wake the visit is abandoned, nothing is closed, and the target's icon and title are restored. → Task 12.
4. The stage tab navigates or closes mid-visit. Abort; nothing is closed. → Task 12.
5. Settings hold nonsense (zero, negative, non-numeric, duplicated or blank list entries). They are clamped on load; a cap of 0 means no stale tab is ever taken. → Task 10.
